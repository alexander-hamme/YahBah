# API and Frontend

## FastAPI (`src/yahbah/api/main.py`, routers in `api/routes/`)
Prefixes: `/applications` (list, `/stats`), `/jobs` (`POST` enqueue -> 201), `/runs` (`GET /{id}`, `/steps` (no code writes `application_step` rows, so it returns nothing), `/artifacts` (only files recorded in `application_artifact`; `trace.jsonl` and the `llm/` logs are on disk only), `/status-updates`, artifact download, `POST /bulk-delete`, `/{id}/cancel`, `/{id}/retry`, `DELETE /{id}`), `/scheduled` (create, list, `/stats`, get, `approve`/`reject`/`hold`/`promote`, delete). Response models are Pydantic classes in the route files and `schemas.py`. Also `GET /health`, `POST /gmail/poll`, `POST /gmail/alert-poll` (manual poller triggers) in `main.py`. Runtime settings: `GET /settings`, `PUT /settings/{key}` in `main.py` (backed by `config/settings.yaml`). Run: `uv run uvicorn yahbah.api.main:app --reload --port 8000` (binds 127.0.0.1).

**Local-only, no auth.** `main.py` rejects any request whose `Host`, or `X-Forwarded-Host` when present, is not `localhost`/`127.0.0.1` (400; blunts DNS rebinding). The Next `/api` rewrite sends `Host: localhost:8000` and the browser's host in `X-Forwarded-Host`, so both are checked. IPv6 literals (`[::1]`) are not accepted. API test clients must use `base_url="http://localhost"`. Do not expose either port beyond loopback without adding auth first.

## Frontend (`frontend/`, Next 16.2.1 / React 19)
App routes `src/app/{page,applications,scheduled}`; components in `src/components` (application list, status pipeline, run info card, step timeline, artifact viewer, submit form, testing toggle); API client `src/lib/api.ts`, types `src/lib/types.ts` (must mirror API response schemas). `frontend/AGENTS.md` warns this Next version has breaking changes: read `node_modules/next/dist/docs/` before writing Next code. Dev: `npm run dev` in `frontend/` (`next dev -H 127.0.0.1`; `start` is bound the same way, so the dashboard and its `/api` proxy are not reachable from the LAN).
